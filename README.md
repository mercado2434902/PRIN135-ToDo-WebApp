# PRIN135-ToDo-WebApp (HTML + CSS only)

This version uses only HTML and CSS. It includes the ToDo List layout, sample tasks, working task checkboxes, and CSS-only All / Active / Completed filters.

## Important limitation
HTML and CSS alone cannot dynamically add new tasks, delete tasks, edit task text/hours, or perform bulk actions such as Mark all done and Clear completed. Those behaviors require JavaScript or a server-side backend. The Add, delete, and bulk-action elements are shown as part of the requested interface but are not functional in this CSS-only version.

## Files
- `index.html` — page structure and sample tasks
- `style.css` — styling and CSS-only filters

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a repository named `PRIN135-ToDo-WebApp`.
2. Upload `index.html` and `style.css` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
